First public release of **MarkItDown GUI**, a portable Windows app for converting documents to Markdown with [Microsoft MarkItDown](https://github.com/microsoft/markitdown).

## Download

Download **`MarkItDown GUI.exe`** below, put it in any folder and double-click it. No installer, no admin rights, no Python needed.
On first launch the app sets up its own private Python and MarkItDown automatically (a few minutes, about 500 MB, once).

> Windows may show a SmartScreen warning because the app is not code-signed. Click **More info**, then **Run anyway**.

## Features

- Drag and drop files and folders, batch conversion, parallel jobs and Stop
- Saves next to each original file, or to a folder you choose; never overwrites unless you allow it
- Open, Show in folder, Retry and full error details for every file
- Every MarkItDown CLI option: embedded images, plugins, input hints, Azure Document Intelligence and Content Understanding
- Automatic first-run setup with a private Python runtime
- Release checks with one-click MarkItDown updates
- Fully portable: settings and runtime stay next to the `.exe`

## Requirements

64-bit Windows 10 or 11, and internet access on first run.

See the [README](https://github.com/mohdbushnaq/markitdown-gui#readme) for screenshots and full instructions.
